# MBTI Personality Prediction Web Application Using NLP

## 📌 Overview
This project presents an NLP-based personality prediction system that classifies users into one of the 16 Myers-Briggs Type Indicator (MBTI) personality types by analyzing textual input. Instead of using a single multiclass model, the system employs a four-axis binary classification approach, where each MBTI dimension is predicted independently using Naive Bayes classifiers. This approach improves prediction reliability and provides a practical application of Natural Language Processing and Machine Learning in behavioral analytics.

---

## 🚀 Features

- Automated text preprocessing, including cleaning, tokenization, and stop-word removal.
- Feature extraction using Bag of Words and TF-IDF techniques.
- Four independent binary classifiers for predicting each MBTI dimension.
- Generation of one of the 16 MBTI personality types from the predicted dimensions.
- Interactive Streamlit web application for real-time personality prediction.

## 🎯 Objective

Traditional personality assessments often rely on lengthy questionnaires and manual evaluation. 
This project demonstrates how Natural Language Processing and Machine Learning can automatically predict personality traits from written text, enabling faster and more accessible behavioral analysis.
